# Task SIKALANSIA (Sistem Informasi Pengelolaan dan Visualisasi Data Posyandu Lansia)

## Role
- Operator (memegang seluruh sistem)
- Kader (hanya bisa input data pengunjung)

## Fitur
- Tambahan Fitur: Monitoring aset seperti timbangan, tensi meter & meja
    - Foto
    - Nama
    - Stok
    - Kondisi
    - Tanggal masuk stok baru dan sebelumnya
- Tambahan Fitur: Monitoring Stok Pemberian Perlakuan (Vitamin, Stick Gula darah, diabetes, kolesterol)
    - Nama Barang
    - Stok Tersedia
    - Terpakai
    - Sisa

## Sorting
- Urutkan list lansia berdasarkan abjadnya di web maupun di laporan

## Dashboard overview ditampilkan sesuai periode/bulan
- Penampilan dashboard sesuai bulan dan nama bulannya dicantumkan

## Laporan
- Tanggal Tanda tangan bisa diedit
- Tanggal print dokumen dari web ditaruh di footer terakhir
- Ada bug pada halaman terkahir yang kosong
- Beri highlight kategori dengan warna untuk kondisi yang berbeda beda
- Tambahkan tanda tangan semua kader yang terdaftar: (sebelah kiri)
    1. Nama (ttd)
    2. Nama (ttd)
    3. Nama (ttd)
- Tanda Tangan di kanan Kepala Desa, Bidan, Kaur
